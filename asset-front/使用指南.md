# 智能资产管理系统 - 使用指南

## 🎯 界面介绍

### 主要区域
- **顶部导航栏**: 显示系统标题、令牌状态和连接状态
- **对话区域**: 与智能助手进行自然语言交互
- **输入框**: 输入您的需求和指令

### 状态指示器
- 🟢 **已连接**: 系统正常运行
- 🟡 **连接中**: 正在建立连接
- 🔴 **连接失败**: 网络或服务异常

## 💬 对话功能

### 消息类型
- **用户消息**: 右侧显示，紫色渐变背景
- **助手回复**: 左侧显示，白色背景，带蓝色边框
- **打字动画**: 助手思考时显示动态点点

### 交互特性
- 消息气泡带有尾巴指向效果
- 头像带有在线状态指示器
- 悬停时消息会轻微上浮
- 发送按钮带有光效动画

## 🔧 功能说明

### 自动令牌配置
系统已内置以下令牌：
- **用户令牌**: `cn-8cb357d5...87ee8`（部分显示）
- **客户端令牌**: `cn-1e522f6f...86c`（部分显示）

每次请求会自动添加这些令牌，无需手动输入。

### 支持的操作

#### 资产管理
```
查询所有未分配的资产
查询状态为VALID的资产
查询包含"广联达"的资产
```

#### 成员管理
```
添加企业成员：用户名test123，密码Pass@123，姓名张三
查询所有企业成员
查询用户名包含"张"的成员
```

#### 权限分配
```
为用户张三分配资产编号ASSET001
取消用户李四的资产ASSET002权限
将资产ASSET003分配给成员ID为123的用户
```

#### 产品查询
```
查询资产ID为12345的产品详情
查询资产ASSET001下的所有产品
```

## 📝 使用技巧

### 自然语言输入
- 使用完整的句子描述需求
- 可以包含具体的参数值
- 支持中文和英文混合输入

### 示例对话
```
用户: 我想查看所有未分配的云锁资产
助手: 好的，我来为您查询未分配状态的资产...

用户: 为新员工王五创建账号，密码设为Abc123456
助手: 我来为您添加新的企业成员王五...

用户: 把刚才查到的第一个资产分配给王五
助手: 我来为王五分配资产权限...
```

## ⚡ 快捷操作

### 键盘快捷键
- **Enter**: 发送消息（单行时）
- **Shift + Enter**: 换行
- **Ctrl + A**: 全选输入内容

### 界面操作
- 点击清空按钮清除所有对话记录
- 消息区域支持滚动查看历史记录
- 输入框支持多行文本和自动调整高度

## 🔍 故障排除

### 常见问题

#### 连接失败
1. 检查后端服务是否启动
2. 确认网络连接正常
3. 查看浏览器控制台错误信息

#### 请求超时
1. 检查网络延迟
2. 确认MCP服务器运行正常
3. 尝试重新发送请求

#### 功能异常
1. 刷新页面重试
2. 检查输入格式是否正确
3. 查看助手的错误提示信息

### 技术支持
如遇到其他问题，请：
1. 记录错误信息和操作步骤
2. 检查浏览器兼容性（推荐Chrome 60+）
3. 联系技术支持团队
